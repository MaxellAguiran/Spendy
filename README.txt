- assets/dragon-head.svg        dragon face, used in headers and footers
- assets/dragon-wave.svg        full waving dragon, used in the big hero areas

The dragon artwork is hand-built SVG. To replace it with your own logo,
swap the two files in assets/ keeping the same filenames, or edit the
<img src="..."> tags in the HTML.

CONTACT FORM
The form on dragon-analytics.html opens the visitor's own email app with
the message already filled in. The destination address is set in ONE place:
the line reading   var TO = '...'   inside the <script> block at the bottom
of dragon-analytics.html. Change that line to change where messages go.

Note: this form needs no signup and no server, but it only works if the
visitor has an email app set up. If you later want messages to arrive
without that, replace the script with a hosted form service.

WRITING STYLE
All pages are written in simple English on purpose, because many clients
are not native English speakers. If you add new text, please keep sentences
short and explain any business term the first time you use it.
