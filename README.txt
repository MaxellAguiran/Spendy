RUNTIME
The deployed site is plain HTML, CSS, JavaScript modules, JSON, CSV,
fonts, and images. It has no framework, backend, tracking, form provider,
database, cookie, login, or build requirement at runtime.

CONTACT
Public contact uses a direct mailto link and an accessible Copy email
control. No visitor data is collected by the site.

SYNTHETIC LABORATORIES
The laboratories are demonstrations, not client engagements or claims of
realised business performance. Their data and results are generated by:

  npm run generate:labs

The generator uses fixed seeds and writes versioned lab-evidence/v1 JSON
plus downloadable CSV files under labs/data/. The marketing recommendation
is emitted only when its model beats the declared holdout baseline.

RESEARCH INTEGRITY
tests/fixtures/article-body-hashes.json freezes the normalized visible text
of all five published article bodies. Run the test suite after any article
markup change. Source labels remain plain text and carry a source-review
attribute until an exact official destination has been verified.

SOCIAL CARDS
tools/social-card.html is the deterministic HTML/CSS template.
tools/social-cards.json contains exact route copy. Regenerate PNGs with:

  npm run generate:social

Set SOCIAL_CARD_BROWSER to a Chromium executable when system Chrome is not
installed at the default macOS location.

LOCAL DEVELOPMENT
Install development-only QA dependencies:

  PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm install

Run a local preview:

  python3 -m http.server 4173 --bind 127.0.0.1

Run all checked validation:

  npm test

Individual commands:

  npm run test:unit
  npm run validate:html
  npm run test:browser

The browser suite covers required viewports, overflow, console errors,
mobile navigation, focus, FAQ state, copy feedback, no-JavaScript behavior,
reduced motion, failed assets, fail-closed evidence, accessibility tables,
automated WCAG 2.2 AA checks, and homepage transfer size.
